# Locations

KB docs for CareerForce's custom code covering locations and location groups: group types and memberships, sharing content across locations, announcements and regional contacts. They are for developers and QA engineers.

Source: `master` at commit `db37480b7` (2026-10-28).

| Doc | What it covers |
|---|---|
| [location-groups-and-memberships.md](location-groups-and-memberships.md) | Group types and roles, member locations, `LocationAssignmentAccessCheck`, the Back to Group block, the group membership audit log. |
| [location-content-availability.md](location-content-availability.md) | Assigning group content to locations: the per-content and per-location availability forms, their access check, provider network leases, and the Manage Availability and Shared Content blocks. |
| [location-announcements.md](location-announcements.md) | The `announcement` entity: group and location notices, management pages, access, the public block, cron purge. |
| [regional-team-block.md](regional-team-block.md) | The "Meet Your Regional Team" contacts block on Region pages and its settings form. |
