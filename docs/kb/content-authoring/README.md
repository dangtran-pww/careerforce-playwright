| Doc | Covers |
|---|---|

| [content-blocks.md](content-blocks.md) | Generic `careerforce` block plugins: Anchor Link, Newsroom Article Search, Configurable Links, Quick Links, Taxonomy Vocabulary, Entity Edit Form, Flag Action, GovDelivery, Register To Vote, configurable-layout Views exposed filter |
| [ckeditor-plugins.md](ckeditor-plugins.md) | CKEditor 5 Accordion Item (`cf_accordion_item_ckeditor`, rendered through the theme SDC) and Anchor/Jump Link (`cf_jumplink_ckeditor`) plugins and their text filters |
